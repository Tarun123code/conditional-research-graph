# Conditional Research Graph

A Python project built using LangGraph to demonstrate conditional routing between an AI agent and tools.

## Features

- State management using LangGraph
- Conditional routing based on the latest AI message
- Tool execution and agent looping
- Graph compilation and execution

## Tech Stack

- Python
- LangGraph
- Groq
- Pytest

## Installation

1. Clone this repository.
2. Create and activate a virtual environment.
3. Install dependencies:

   ``bash
   pip install -r requirements.txt

## Configure the required API key securely using an environment variable.
## Run the application: python main.py
